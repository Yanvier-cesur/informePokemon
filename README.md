# Informe Pokémon

#Descripción

Aplicación Java que lee un archivo pokemon.json, procesa los datos de los Pokémon y genera un informe en pokedex.txt.

# Estructura del Proyecto

Pokemon: Modelo de datos.

FileService: Lectura de JSON y escritura de archivos.

InformeService: Generación del informe.

Main: Clase principal de ejecución.

# Uso

Colocar pokemon.json en la raíz del proyecto.

Ejecutar la clase Main.java.

Revisar el archivo generado pokedex.txt.

# Requisitos

Java 17 o superior.
